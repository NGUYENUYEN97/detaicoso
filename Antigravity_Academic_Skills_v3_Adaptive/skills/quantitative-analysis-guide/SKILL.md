# Quantitative Analysis Guide

## Mục tiêu
Hướng dẫn tác giả xử lý dữ liệu khảo sát bằng Python theo quy trình minh bạch, tái lập và phù hợp câu hỏi nghiên cứu.

## Quy trình 8 bước
1. Nhập dữ liệu.
2. Làm sạch dữ liệu.
3. Thống kê mô tả.
4. Kiểm định độ tin cậy Cronbach's Alpha.
5. Phân tích nhân tố khám phá EFA nếu phù hợp.
6. Tạo biến tổng hợp/thang đo.
7. Hồi quy/kiểm định giả thuyết.
8. Trực quan hóa và diễn giải kết quả.

## Nguyên tắc
- Không tự tạo dữ liệu nếu tác giả không yêu cầu dữ liệu giả lập.
- Nếu dùng dữ liệu giả lập để minh họa, phải ghi rõ là dữ liệu giả lập.
- Không diễn giải kết quả vượt quá dữ liệu.
- Kiểm tra điều kiện áp dụng trước khi dùng Cronbach/EFA/hồi quy.
- Mọi biểu đồ/bảng phải có nhãn, nguồn dữ liệu và giải thích.
